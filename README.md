# Angular-Trabalho-Programacao-Web

Requisitos: Angular 22.2.00, NPM 11.17.0

Intalação: npm install -g @angular/cli

Criação da pasta do projeto: ng new <project-name>

Rodando o projeto localmente: npm start

Rodando esses comandos termos uma aplicação com arquivos como "packege.json", que serve como o arquivo de configuraçlão do seu projeto, "main.ts" que seria o componete principal da aplicação;

Utilizando o comando: ng generate component <nome-do-compoente> , criando os arquivos <nome-do-compoente>.css, <nome-do-compoente>.spec.ts, <nome-do-compoente>.ts e <nome-do-compoente>.html;

O angular vai estrutar o projeto entre main.ts e app.ts, onde no main ira chamar a classe criado no app.ts,
e no app.ts chama o componente criado utilziando o comando de cima.

main.ts -> app.ts -> index.html -> contador.ts
